Agents guess. Docs hide.

Today an AI agent that wants to use your documentation must scrape HTML, guess at structure, and cite whatever blog post ranked first — often the wrong version, often without a source. That's slow, fragile, and blind to licensing.

WebMCP flips it. The site publishes tools; the agent reads the contract and calls exactly what it needs. Humans keep the visual web; agents get first-class access.

Without WebMCP
→ fetch page
→ parse unpredictable HTML
→ guess which section matters
→ cite nothing, maybe wrong version
✗ fragile, slow, unattributed
With Documesh + WebMCP
→ agent reads tool contract
→ search_docs_across("edge functions env vars", ["netlify","vercel"])
→ structured results, version + license + canonical link
✓ deterministic, attributed, licensed
