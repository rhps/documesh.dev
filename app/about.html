About Documesh

Documesh is an agent-native documentation search engine built on WebMCP, the open standard for exposing structured tools to AI agents. It federates documentation from 18 vendors — including Cloudflare, Netlify, Vercel, Kubernetes, React, PyTorch, and more — into a single version-cited, license-attributed interface.

Documesh is built and maintained by selatan.org.
