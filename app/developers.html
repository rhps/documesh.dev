Developer Portal

Everything you need to integrate Documesh into your application or agent. No API key required — the API is fully open for read-only access.

Quickstart

Search documentation with a single HTTP request:

curl "https://documesh.selatan.org/search?q=edge+functions+env+vars"

Returns ranked results with vendor, version, license, and canonical source URL for every match.

Agent Mode

Add ?mode=agent to the root URL for a machine-readable view of all capabilities, endpoints, and vendors.

curl "https://documesh.selatan.org/?mode=agent"

Sandbox / Test Environment

Documesh is a read-only, free, open API — the live service at documesh.selatan.org is itself safe to exercise. There are no destructive operations and no production data at risk, so no separate sandbox host is needed.

curl "https://documesh.selatan.org/search?q=test+query"

SDKs & CLI

Official SDK packages are planned for Q4 2026. In the meantime, the API is REST-based and works with any HTTP client. Use the OpenAPI spec with openapi-generator to auto-generate client libraries in your language of choice.
